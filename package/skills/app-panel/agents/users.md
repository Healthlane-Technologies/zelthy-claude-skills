# Manage App Users

## What this does
Add, edit, deactivate users and assign roles.

## Prerequisites
- Inside an app → App Users (sidebar)

## Navigation
`/platform/apps/{uuid}/user-management/`

## Steps

### Add user
1. Click "+ Add User" button
2. Fill: Name, Email, select Role
3. Save
4. User receives login credentials

### Edit user
1. Find user in list (search/filter)
2. Click "Edit" button (blue)
3. Update details
4. Save

### Reset password
1. Click "Reset Password" button (orange)
2. Confirm
3. User receives new password email

### Deactivate user
1. Click "Deactivate" button (red)
2. Confirm
3. User can no longer login

## Page features
- Stats: Total Users, Active, Inactive
- Search users
- Filter by status (All/Active/Inactive)
- Cards/List view toggle
- Pagination
