# Edit Basic Information & Branding

## What this does
Updates app name, description, meta title, logo, and favicon.

## Prerequisites
- Inside an app → App Settings → Basic Information tab

## Navigation
`/platform/apps/{uuid}/app-settings/app-configuration/`

## Steps
1. Click "Edit Details" button (top right, purple)
2. Wait for edit form/modal
3. Update fields as needed:
   - App Name
   - Description
   - Meta Title (shown in browser tab)
   - Logo (file upload - shown in sidebar)
   - Favicon (file upload - shown in browser tab icon)
4. Save changes
5. Verify: values updated on page

## Fields
- App Name: Internal workspace name
- Description: Displayed on app card
- Meta Title: Browser tab title and metadata
- Logo: Displayed in app sidebar, recommended SVG/PNG
- Favicon: Browser tab icon, recommended ICO/SVG, 32x32 or 16x16
