# Launch New App

## What this does
Creates a new workspace/tenant app in the Zango platform.

## Prerequisites
- Logged into App Panel at `/platform/apps`

## Steps
1. Click "Launch New App" button (top right)
2. Wait for modal to appear
3. Fill "App Name" input
4. Fill "Description" textarea
5. (Optional) Click "Click to Upload Template" if user has a template file
6. Click "Launch App" button
7. Wait for app creation (may take 30-60 seconds)
8. Verify: new app card appears in the grid

## Fields
- App Name (required): Identifier for the workspace, no spaces recommended
- Description (required): Human-readable description
- Upload Template (optional): ZIP template file

## After Launch
- Click the new app card to enter it
- Set up themes, user roles, routes as needed
