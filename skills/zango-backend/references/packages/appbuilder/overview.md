# AppBuilder Package Reference

The AppBuilder package provides utilities for building and managing Zango applications.

## What is AppBuilder?

AppBuilder is a utility package that provides helper functions and tools for app development.

**Common Features**:
- App development utilities
- Helper functions for common tasks
- Development tools and utilities

## Installation

Install via App Panel:
1. Navigate to your app in the App Panel
2. Go to "Packages" section
3. Search for "appbuilder"
4. Click "Install" (use latest version)

## Usage

```python
# Import utilities as needed
from ...packages.appbuilder import <utility_name>
```
